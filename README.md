# СКАМ — Android prototype

## Что уже есть
- Фиолетовый интерфейс на Jetpack Compose
- Вкладки «Чаты», «Звонки», «Контакты»
- Локальные демонстрационные диалоги
- Отправка сообщений внутри прототипа
- Добавление контакта по номеру или тестовому ID
- Демонстрационный экран голосового/видеозвонка

## Как открыть
1. Установите Android Studio.
2. Выберите **Open** и укажите папку `SKAM_Android`.
3. Дождитесь синхронизации Gradle.
4. Запустите приложение на эмуляторе или Android-устройстве.

## Важно
Это интерактивный UI-прототип: данные пока хранятся только в памяти приложения. Сообщения не доставляются другим устройствам, а экран звонка не передаёт звук/видео. Для настоящего мессенджера потребуются сервер, регистрация/проверка номера, база данных, push-уведомления и WebRTC для звонков. IP-адрес не используется как способ поиска людей; безопаснее приглашать по номеру с подтверждением или по уникальному ID.
