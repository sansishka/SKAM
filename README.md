# SKAM
СКАМ — современный Android-мессенджер с уникальным фиолетовым дизайном. Общайтесь с друзьями в личных и групповых чатах, отправляйте сообщения, добавляйте контакты по номеру телефона или ID. В приложении предусмотрены голосовые и видеозвонки, удобный список контактов и история вызовов. СКАМ — общение без границ!
